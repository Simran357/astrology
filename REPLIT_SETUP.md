# The Astral Heretic — merged build

This package combines the **Premium AI Astrology Web App** application views with the **Celestial Truths / The Astral Heretic** editorial landing-page system.

## What is included
- Dark editorial Astral Heretic visual system: DM Sans + Fraunces + DM Mono.
- 8-section landing page, footer, manifesto, method, salon menu, midnight letter, inquiry form and FAQ.
- Direct launch buttons into the existing Birth Chart, Today/Dashboard, Consult/Reading, Learn and Profile views.
- Existing premium astrology components/pages retained in `src/components` and `src/pages`.
- Responsive mobile/desktop layout.
- Replit/Vite-compatible project root.

## Run on Replit
1. Import this ZIP as a new Replit project.
2. Run `npm install`.
3. Run `npm run dev`.
4. For a production check, run `npm run build`.

## Design source
The landing page is intentionally implemented as an original merged design using the supplied Astral Heretic styling direction, not as a dependency on the original mockup project.

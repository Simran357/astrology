# The Astral Heretic — Premium Astrology UI

This build keeps the Premium AI Astrology project's existing source structure and behavior as the source of truth, then applies the Astral Heretic / Celestial Truths visual system.

Added as UI-only surfaces: sign in, sign up, timeline/shifts, relationships/bonds, tarot, and Ask The Heretic. These pages do not replace or modify an API, auth provider, ephemeris engine, or backend. Existing Premium pages remain intact.

Run:

```bash
npm install
npm run dev
```
